The Problem

Every Tournament Weekend Starts the Same Way

You're in the parking lot at 7am, phone out, scrolling a 40-page PDF trying to find the pitch count rules. Again.

📄
Different Format Every Time
Every tournament website buries their rules differently. Some are PDFs, some are web pages, some require you to create an account just to see them.
🔍
Rules Are Hard to Find
Pitch count limits, mercy rules, courtesy runner policies — buried in long documents. You're searching for the same information every single weekend.
📱
Parents Ask the Same Questions
Where's the field? What hotel did we book? What time do gates open? The team manager fields the same texts every tournament weekend.
The Solution

One App. Every Tournament. Same Place Every Time.

TourneyNotes gives your team a clean, mobile-friendly app with every tournament's rules and info organized the same way, every weekend.

📋
Consistent Layout
Mercy rule, pitch count, courtesy runner, balks, extra innings — always in the same spot. No searching, no scrolling through irrelevant info.
📍
One-Tap Directions
Field address links directly to your maps app. Parents find the complex without texting the manager at 6am on Saturday.
🏨
Hotel Info Built In
Hotel name, address, and booking link all in the app. Families traveling independently have everything they need in one place.
📲
No App to Download
Works in any mobile browser and installs to the home screen with one tap. Parents don't need to create accounts or download anything.
⚡
Fast Admin Entry
Add a new tournament in minutes from your phone or laptop. Simple form, instant publish — rules are live the moment you save. No spreadsheets, no coding required.
